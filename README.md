Floods are among the most destructive natural disasters, causing significant loss of life, property damage, and economic instability. As climate change, rapid urbanization, and deforestation increase the frequency and severity of flooding, traditional manual monitoring systems often fall short of providing rapid, early warnings. To address this, the Rising Waters – Flood Prediction System was developed as an academic prototype that leverages machine learning to deliver fast, data-driven flood-risk assessments based on weather and environmental parameters. The project follows a comprehensive data science workflow— encompassing data collection, exploratory analysis, preprocessing, and model evaluation. By testing and comparing four classification algorithms (Decision Tree, Random Forest, KNN, and XGBoost), the system identifies and serializes the top-performing model. This model is integrated into a user-friendly web application built with  HTML, CSS, and JavaScript, allowing users to input environmental metrics and instantly receive a risk prediction.
